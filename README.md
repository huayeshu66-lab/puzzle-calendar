# Puzzle Calendar · 可定制谜题日历 Skill

**先了解用途与喜好，再用真实样页确定风格，制作适合纸笔解谜的日历 PDF。** 适用于 Codex，技能版本 **2.3.7**。

## 先玩三页

三张真实 A5 日历分别为 **2027 年 7 月 1 日、3 日、4 日**。展示三种题盘造型、配色和繁简程度；这是三道样题，不是整月或全年成品。

| 日期 | 样页 | 本页选配内容 |
| --- | --- | --- |
| 7月1日 · 星期四 | 单色莲蓬蜂巢数回 | 原创短寄语、随手记、解题用时 |
| 7月3日 · 星期六 | 双色几何三角数回 | 只保留日期与谜题 |
| 7月4日 · 星期日 | 彩色平面群岛桥梁 | 随手记 |

- [日历题页 PDF](demo/trial-calendar-A5.pdf)：三页，不含答案。
- [玩法与答案 PDF](demo/trial-rules-and-answers-A5.pdf)：第一页是玩法，其后三页按日期给出完整答案。
- [完整试玩包](demo/trial-bundle.zip)：以上 PDF、打印说明与许可。

蜂巢数回与三角数回是同一回路规则家族的不同网格，桥梁是另一规则家族。这组展示的是不同题盘与视觉设计，并非三种独立规则。

打印选择 **A5、实际大小／100%、单面**。第一张可黑白打印，后两张使用彩色打印；顶部至少留有18毫米装订空间。请按实际孔径先试印，检查细线、笔迹与装订位置。双色指视觉配色，当前 PDF 不承诺印厂专色分版。

## 日期与谜题是核心，其余按需选择

农历、节气、节假日、寄语、随手记、专用记录、答案二维码等均为可选模块，可以搭配，也可以全部不加。普通随手记与解题用时等专用记录分别选择；事实信息按地区、年份和来源核对。

不知道喜欢什么风格，可以先看参考与真实样页，保留喜欢的局部，再调整构图、字形、颜色与题盘外观。候选全部不合适时继续探索，不局限于本页的三个主题。风格确认后，再制作指定月份或范围。

## 它怎样制作

1. **理解用途。** 确定日期范围、使用者、打印条件和内容选择，沿用已知偏好，不反复提问。
2. **先看样页。** 日期、谜题、插画和书写空间共同设计；先确认真实效果，再批量排版。
3. **核对内容。** 按题型验证题目与答案，检查重复、日期、字体、可读性和书写空间；分别记录数字文件检查与实物试印。
4. **按需交付。** PDF 题页、规则和答案可以分开；二维码图形答案可用用户自己的账户托管，需核对链接与扫码体验。

题盘可以采用蜂巢、三角、圆形通道、自然轮廓或无整体边框。外观变化须保留真实规则结构与线索归属；“解答后显现”只作少量点缀。设计储备不等于每种题材都已内置一键生成。

## 先生成一张 PDF

[入门示例](examples/README.md) 使用自带的圆形迷宫代码，只需 **Python 3.11+、Node.js 和 ReportLab**，无需先配置外部多题型引擎。

在仓库根目录运行：

```bash
python3 -m pip install -r examples/requirements.txt
python3 examples/first_calendar.py --date 2027-07-02 --output ./my-first-calendar
```

得到日历、答案和玩法三个 PDF。默认英文，便于先验证新环境；传入可嵌入中文字体可切换中文。这个最小示例与上方宣传样页独立，不代表其他题型与信息来源已配置完成。

## 安装技能

下载 [puzzle-calendar-skill.zip](puzzle-calendar-skill.zip)，解压后把 `puzzle-calendar/` 放入 Codex 的 skills 目录（默认 `~/.codex/skills/`）。已有同名技能时，先保留自定义内容，再决定替换。

在新对话中调用 `$puzzle-calendar`，例如：

> 用 puzzle-calendar 制作2027年7月的成人谜题日历，A5，顶部预留装订空间。先比较单色简约、双色适中和彩色极繁的样页，确认风格后再做整月。随手记可选，玩法和答案单独提供。

## 当前能力与依赖

| 内容 | 当前情况 |
| --- | --- |
| 日期计划、任务记录、PDF 排版与交付检查 | 已有脚本，按实际纸幅、题量与模块组合核对 |
