# Puzzle Calendar · 谜题日历 Skill

版本 **2.3.5**。面向 Codex 的可打印谜题日历制作技能，支持需求澄清、同内容风格样页比较、日期计划、题目与答案核验、版面检查和分范围交付。

## 安装和使用

把 `puzzle-calendar/` 放入 Codex 的 skills 目录（默认 `~/.codex/skills/`），在新对话中调用 `$puzzle-calendar`。例如：

> 用 puzzle-calendar 制作 2027 年 1 月成人谜题日历，A5 黑白，预留打孔和随手记空间。先比较风格样页，确定后再制作整月。

已有同名技能时先保留原版本及自定义内容，再决定替换。本仓库中的技能包与源码文件内容一致。

## 依赖与边界

日期计划器需要 Python 3.11+。PDF 和原生谜题依赖另外安装的 `puzzle-publisher`、ReportLab、pypdf 与可嵌入中文字体；部分形态或扩展题型还需要 Node、Z3、cspuz 或外部生成器。详见运行文档；本仓库不包含全部外部引擎、商业中文字体和专业排盘技能。参考文档中的开发机器路径属于历史接入记录，需要在使用者环境重新定位。

默认先确认风格再批量制作；题目、答案、日期、视觉效果与实物打印分别检查。二维码答案可按需通过使用者自己的 Cloudflare 账户发布，实际网络访问仍需验证。
