# 一本可以玩的日历

把每天的一道谜题，做成喜欢的日历。

这次准备了三种真实可打印的样页：单色莲蓬蜂巢数回、双色几何三角数回、彩色平面群岛桥梁。题盘结构、构图和繁简程度各有变化。

日期与谜题是核心，农历节气、节假日、寄语、随手记、专用记录和答案二维码等模块按需选择。不知道喜欢什么风格，也可以先看小样、比较局部，再决定。

随附三页A5试玩PDF，玩法与答案另册。欢迎试印、解题，并告诉我们具体哪一处好用或不好用。

附件：三种风格试玩包.zip

制作自己的版本：使用Puzzle Calendar Skill，告诉它用途、日期范围、打印条件与喜好。运行环境和内容模块按实际需求配置。
