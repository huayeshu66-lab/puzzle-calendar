# 首发文案

建议标题：给2027，做一本能玩的日历

我想给2027做一本能玩的日历。

日期要一眼看清，谜题要有趣，题面也可以有自己的样子：蜂巢变成莲蓬，迷宫围成圆环，岛屿之间等待你架起桥梁。

页面还要留得下笔尖，以及随手记下的小事。

于是，我把这套制作方法整理成了一个Codex Skill：Puzzle Calendar。

它会先了解你的用途和喜好，通过样页确定风格，再继续制作日历PDF。不知道自己喜欢什么，也可以从比较开始。

这次准备了三页A5黑白试玩日历，玩法和答案单独提供。想玩的人，可以先打印；想自己制作的人，可以到GitHub查看安装说明和最小运行示例。

正在寻找第一批试用者。我想知道：你愿意把哪一页放在桌上？真正打印和解题时，哪里还需要改？

项目入口：https://github.com/huayeshu66-lab/puzzle-calendar

制作说明：使用Codex与AI工具辅助设计，谜题结构与答案另行核验。
