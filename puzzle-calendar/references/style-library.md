# 日历备用风格库

版本：1.11。风格选择使用英文 `style_id`，中文名只用于沟通。下列七种是当前已接入的原创版式，不是品牌同款模板。新方向可另行设计与验证；表中纸幅、颜色、装饰和字号不是所有任务的通用规定。

黑白赛博1.2版日号84pt、年份11pt、月份22pt、竖排星期12pt；当前A5模板题板上界固定70mm、下界162mm。节日／节气在日期区x62mm、y47mm起排；名称12pt，时间11pt横排，完整信息超出日期区时明确失败，不悄悄留在寄语旁或丢弃。纯汉字2–5字题名以11pt正向竖排在x18mm、y172mm起排；答案另有横排“答案”。超长或含标点题名退回横排。寄语左边界34mm、起点173mm，正文与署名横排；字位距按实际字框＋净空测量。真实引用用11pt正文、9.5pt独立署名，按实际字段合计高度验收；当前模板不自动缩字容纳长引文。日页和对应答案页的上方20mm无内容，规则手册同步留白。其他样式保持原有12mm，不能把赛博的打孔适配外推到其余样式。这些是该预设的现状；自定版式可在用户约束与实际可读可写的范围内调整字级和题板尺寸，重新核验。

## 整页与题面一同设计

极繁等高细节方向先读 [极繁设计方法](maximal-design.md)。旧参考中的植物雕版、复古印刷、装饰艺术、纸艺拼贴应拆成构图、用色、字体、线条与材质的组织方法，迁移到当前用户的题材；它们不是四个固定主题，也不是新增的内置 `style_id`。

风格比较使用同日同题、相同信息与打印条件。每个方向应在整体主视觉、构图、字体角色和纹样节奏上形成可辨区别；仅换字体、颜色或随手贴叶片、圆圈不算完整方向。配色变体可作为同一方向的比较，不冒称新风格。

题面可延续页面的母题，形成一张完整设计：例如植物刻线与黑格肌理、页边波纹与填纹、书页排线与双框、日期块与圆角格盘。这些是可选的设计方法，不限定题型、纸幅、颜色或候选数量。线索数字周围留净空，纹样不得像新增线索或答案标记；圆角、间隙与描边后的有效作答面积须按实际尺寸测量。

重绘可改变题面字体、线条、填纹和外轮廓，保留原题的线索归属、邻接／连通拓扑和答案语义。原始坐标保留为核对依据；派生稿允许经检查的位置与曲线映射，依赖行列对齐的玩法仍须保留其规则关系。原始题板、源哈希、稳定ID、结构数据及答案不覆盖；派生（`derived`）矢量独立保存并计算新哈希，从实际PDF核对语义、位置与清晰度。仅凭原题验解通过不能宣称派生稿无误，详见 [设计评审](design-review.md)。当前内置模板的默认题板不因此自动获得重绘能力。

| 类别 | 制作与使用边界 |

## 当前内置样式的共用约束

- 年、月、日、星期由日期计划生成，四项清楚可见；月份不能藏在辅助行，日号不能孤立。成组表达完整日期时不再重复ISO行。
- 白色作答区与必要线索始终完整。题名11pt在完整题面下方，赛博可用窄栏竖排；寄语归下方阅读区。仅cyber-noir已将节日／节气归日期区，其余六种预设尚未统一这一路由，选用时核对实际位置与需求。其他信息按样式支持范围排版，按实际字宽和总高度测量。默认不加信息标题、玩法提示或性质标签。
- 四周至少12mm是当前预设的安全边界，装订等需要更严格禁区时按实际条件重算。普通题面数字12pt、可书写方格7mm是常用起测值；不同题型与自定版式按 [打印验收](print-design.md) 核对实际可读可写范围，不把这些数值套用为所有设计的下限，也不为装饰突破用户锁定要求。
- 同日同题的风格比较页保留相同线索、答案、完整题板范围和打印尺寸；对应答案页的题板位置与比例一致。不因换样式重新生成一道题，多个比较稿在正式派题账本只计一次。
- 默认不印日历总标题、内部题号、当前页／总页数、“娱乐”或制作状态。`book_title` 仅为PDF元数据；用户未提供页脚文字或logo时，页脚留空。来源、性质和制作说明放在回复与交付说明。
- 黑白版不是自动转灰截图。大色底移除，关键区别用字重、位置、线条承担，白底题面与深色线索保持清楚；不依赖颜色解释玩法。
- 装饰与谜题的符号、格线保持明显区分。没有实际工艺用途时不画装订孔；不补假月相、品牌logo或无功能英文标语。

## 字体、可移植性与失败状态

本包附 Work Sans Bold／Regular、Lora Regular、Tektur Medium 和各自 OFL 许可。暖橙编辑、瑞士大字、自然植物、几何轻趣使用当前经过检查的中文主字体。东方书卷、复古报刊及黑白赛博的寄语需要合格中文宋体：优先检查本机 Songti 的简体常规字面；也可通过 `appearance.serif_font_path` 指定可读的绝对 TTF／TTC 路径。自动 Songti 取SC-Regular字面；用户指定TTC取首字面，并核对实际中文覆盖和嵌入。

所需字体缺失、缺字、不可嵌入或文件不合格时明确失败，指出受影响样式；不能静默替换后仍称原样式。中文字体不得因本机存在就当作可再分发素材打包。每套建议2–3家主要编辑字体，固定大日期、年月星期、寄语署名的角色；不要求所有样式同时使用三家。可按月份换字面，同月保持稳定；目前按独立月份任务配置和验证，未内置自动月份字体调度。直接复用源题板时保留其原字体和几何；需要题面参与设计时按上文生成派生稿，不为凑字体家数重绘。黑白赛博原型编辑部分三家；本次一月扩展题板自带Helvetica，实际PDF总共四家，这是该项目的资产事实，应在制作记录中明确区分，不作为其他任务的字体配额。最终PDF逐一检查所有实际字体资源的嵌入与字形。

## 接口与适配范围

七种样式通过独立 `appearance.json` 选择：

```json
{
  "layout": "editorial",
  "style_id": "swiss-type",
  "serif_font_path": null,
  "book_title": "",
  "show_information_titles": false,
  "show_rule_hint": false,
  "show_puzzle_id": false,
  "show_page_number": false,
  "footer": null
}
```

省略 `accent_color` 才采用所选样式的默认色；显式值必须为 `#RRGGBB`。示例字段是制作配置，不需要用户逐项回答。完整合同与命令见 [运行接口](runtime.md#页面显示配置)。

当前七种均限定 `daily`＋`portrait`、`instructions=reference` 或 `none`、`show_rule_hint=false`。`reference` 另附完整 `guide.pdf`。用户要每页完整简则、首次页内规则、周／月、横版等，应使用 `classic` 或另行实现并通过相同验证，不能悄悄丢掉要求。CLI默认 `classic` 仅为旧任务兼容；classic只接受默认 `style_id=warm-editorial`，未知ID、非默认样式搭配classic及其他显式不兼容组合均应报错。

纸幅、题型、外部线索与信息容量逐项实测。A5独数样页通过，不代表A5可容纳所有题型，也不代表七种样式已经覆盖全部日历制式。下方信息放不下时，先在用户约束内调整内容或另行设计版式并核验；当前模板容量不足仍须报告，不自动截断、缩字或删模块。

制作资料保存 `style_id`、样式版本、实际字体路径与哈希、字体解析结果、设计来源与布局报告。同题比较另记 `comparison_group_id`、共同日期／`puzzle_id`、打印条件、推荐理由和用户反馈；比较稿是替代方案，正式派题账本只计一次。

## 样页验证过的设计方法

**题盘与主题造型融合，主体细密、书写区留白。** 让题盘的轮廓与单元构成主题物，丰富细节集中于主体自身，日期和普通记事有清楚、连续的空间。细密刻纹莲蓬是已获用户美感认可的案例，但用户明确认为它不是所需的极繁；不把两项评价合并，也不据此默认选定整月风格。

主题物需另做 [日期对应检查](design-review.md#主题物与日期对应)：莲蓬优先纳入夏季主题计划，实际生长阶段和使用地区决定适用窗口；节庆意象核对目标年份的日期。现有1月1日莲蓬样页只证明造型思路，不作为元旦季节适配范例。

这是一种可复用设计方法，未新增内置 `style_id`，不改变上述七种预设的能力声明。其他主题须重新寻找相容结构并核对题意。具体方法、使用空间和认可范围见 [设计评审](design-review.md#题盘与主题造型融合主体细密书写区留白)。

| --- | --- | --- |
| 摄影／艺术图版／博物馆日历 | 清晰且已授权的照片或图版、正确题注与来源 | 不用假照片、假馆藏或来路不明图像；可先提供仅版式的原创样页 |
| 科学植物插画／物种知识 | 已授权或原创科学插画，以及核对过的名称与短注 | 原创装饰叶枝只叫装饰，不能充当科学图鉴 |
| 真实月相／天文日历 | 可靠计算或来源、日期与时区对应、正确图例 | 不用随机圆形当成真实月相；未取得数据不声称已内置 |
| 立体纸雕／逐层撕页／拼装摆件 | 结构设计、纸张与裁切参数、装订／支架工艺、实体原型验证 | 只交付清楚标明的平面灵感版；家用PDF不冒称已实现立体机关 |
| 更多季节变体或个人主题 | 明确主题、所需原创／授权资产、完整日期与题面容量检查 | 保留当前风格骨架，不每天随机换字体、题面符号和整套配色 |

这些方向供后续设计选择，不属于传入一个当前 `style_id` 就能获得的功能。用户确实需要时，检查实际工具与资产、完成相应制作和验收；不要为了套用现有七种而丢掉其要求。

## 用户不知道喜欢什么时

按已知用途、受众与打印条件选少量有实质区别的方向，先供样页让用户确认，再扩展整本；用户明确委托自主定稿时可跳过风格确认。说“你推荐”授权推荐，说“试试蓝色”授权试色，都不等于最终选定。

优先用同日同题的实际PDF比较排版和作答体验；先探索配色或构图时也可提供标明类别的概念预览。成人黑白也可用强字形构成、完整雕版插画、连续纹样或克制书页拉开差异；彩色再比较色块与正负形关系。候选不局限于现有库，不先制作多套全年，也不把风格库变成新的必填问卷。

用直观语言介绍：“这一张利落省墨”“这一张像安静的书页”“这一张多一点自然感”。接受“字大一点”“太花”“更喜欢B的日期”等反馈。已有偏好和授权直接沿用，用户不必解释字体术语，也不必先学会命名审美；完整处理见 [需求收集](intake.md#不知道风格时)。
