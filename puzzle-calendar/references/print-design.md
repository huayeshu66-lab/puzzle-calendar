# 排版与打印验收

## 视觉系统

先依据brief建立theme_tokens：style_id、字体角色／字号、间距mm、配色、线宽pt、装饰量、日期层级和月份变体。全年保留可识别的阅读逻辑；按月变化字体、颜色或构图时分别验证，玩法相同的必要符号保持一致。运行样式与设计来源见 [风格库](style-library.md)，审美与阅读判断见 [设计评审](design-review.md)。

| style_id／方向 | 版面语言 | 黑白实现 |
| --- | --- | --- |
| warm-editorial／暖橙编辑 | 明确的日期带、大日号、板下题名和下方信息 | 去大色块，保留日期组和轻线 |
| swiss-type／瑞士大字 | 无衬线字面、大小对比、清楚对齐和留白 | 靠字重、比例与单线维持层级 |
| eastern-book／东方书卷 | 中文宋体与衬线数字、克制线框、书页秩序 | 清楚字形、少量线框，白底题区 |
| newsprint／复古报刊 | 衬线日期、栏目式秩序、双线分隔 | 避免纸噪点与大灰底，不制造旧纸纹 |
| botanical／自然植物 | 原创矢量叶枝角饰、柔和色调、净空题区 | 边缘线描，不侵入作答网格 |
| geometric／几何轻趣 | 日期与少量几何元素成组，易读字面 | 图形仍清楚，装饰不误作题目线索 |
| cyber-noir／黑白赛博 | Tektur机械数字、断轨切角；当前原型顶部预留20mm | 黑字白纸，不靠霓虹颜色，不加入无用状态文字 |

这七种是editorial竖版每日页的运行样式，日期结构、字体和装饰安排有实际差异，不只是换色。具体tokens、样张和适配范围以风格库及最终PDF为准。classic的minimal/newspaper/chinese/modern仍用于旧模板兼容，不与七种style_id混为一套；classic只接受默认warm-editorial值。用户需其他审美时用当前设计及PDF能力实现同等可靠的版式，保留内容记录。

## 参考日历与原创设计

读取 [日历设计调研](calendar-design-research.md) 和 [风格库](style-library.md)。参考Stendig、Timor、Fedrigoni 365、故宫日历、单向历、Rifle Paper Co.、V&A、Pirelli、MoMA月相等不同类型案例时，优先访问品牌、发行方、设计师或博物馆原始来源，并尽量查看真实内页，不能只读营销文案或只看封面。记录来源网址、版本、可访问的样张、观察范围和无法确认的项目。

把三类证据分开：官方事实（已明确的字体、颜色或设计意图）、目视分析（日期组合、图文比例、字形角色、留白与对齐）、应用推论（我们如何用于纸上解谜）。字体名称需要官方证据；只看图片时可说粗无衬线数字、中文衬线正文等角色，不能认定为Helvetica或其他具体商业字体。我们的字面使用获许可的Work Sans Bold／Regular、Lora Regular、Tektur Medium，按风格分配角色，不冒称品牌同款。中文宋体须检查本机Songti或appearance.serif_font_path对应可嵌入TTF／TTC；本包不附商业中文字体，所需字体缺失不能静默回退。

借鉴结构与节奏，不复制logo、源谜题、产品照片或装饰资产。用户参考图中的孔洞与装订位置只有符合实际工艺时才纳入设计；不加假孔、不将宣传标题或参考说明印进玩家页。完整规则、详细来源与内容性质可另附，页内只保留使用所需的信息。摄影、馆藏图、真实月相、立体刀模保留为有条件方向：需要授权图像、核对过的数据或可验证工艺；无资产时不使用假照片／假馆藏／假月相填充。植物样页角饰为原创叶枝，只用于装饰，不冒充品牌插画或当日物种知识。

## 空间与文字

运势参考黄历的字段组织：常用2–6字段、值以2–4字短词为主、宜／忌每栏2–3项；约20–50字总量仅是编辑起点。当前两栏helper采用标签12pt加粗、值11pt、栏间8mm；信息块标题默认隐藏，不加“娱乐”等性质标签。用户开启有用的标题时用9.5pt辅助字号。两栏各自按最长标签对齐值，靠空白分栏。日期为主层级，星期／农历为次级，信息与谜题明确分区。复核实际字段宽度和多模块总高度；字段不适配先按已授权目标调整内容，当前helper不自动截断或缩字，需变更版式时重新核验，长篇依据另附。寄语可用15–25字短句。真实引语使用quote.text，署名使用quote.attribution独立9.5pt排版；不把作者挤进正文，带署名不支持fields。本次赛博原型的日页／答案及规则手册顶留20mm，打孔示意另附，按实际装订器孔距打孔；其他任务按实际装订需求设计，不继承这个孔区数值。内容性质与来源留metadata及回复／交付说明。这些产品目标不替代下面的实际几何与字体检查，也未声称量测某张黄历实物。

每日页有两套显式骨架。`editorial` 通过style_id选择七种设计，默认warm-editorial用11pt年份、22pt月份、14pt星期和68pt日号形成日期组，年月日完整且月份明显，不重复ISO行。暖橙编辑彩色版日期带使用强调色；各样式保持白色作答区、板下题名与下方已选信息，日期构图、字体和边缘组织分别设计，具体tokens见风格库。黑白版保持各自构图，去掉大墨底并用文字、线条维持分区。下方信息先测量总高度，题板上下边界据此确定；当前模板放不下时明确拒绝，不自动缩字、缩格、删模块或挤入页脚。需改变字级、题板范围或信息布局时，在用户约束内另行设计并核验。`classic` 保留18pt月份与56pt日号、14pt星期、10ptISO日期和13pt题名，供旧任务及页内规则使用。两者均不重复日历总标题。字体OFL许可随包保留；上述字号是本产品选择，不是品牌日历实测数值。

editorial的七种样式目前只适用于daily＋portrait、reference／none、show_rule_hint=false。新手页内完整简则、every_puzzle、月／周和横版须选classic或另行实现同等验证；classic不能同时选非默认style_id，显式不兼容配置报错，不静默回退或丢弃规则。新制连续使用的竖版每日历优先推荐editorial，CLI默认classic只为兼容旧任务。两者仍按真实题型、纸幅、大字和装订需求计算fit_matrix，不能把一张A5样页推广成所有组合均适配。换style_id只重新排版和检查适配，原日期、题面语义、线索、答案与稳定ID冻结；原源板保留不覆盖。明确重绘题面时另存derived矢量与哈希，核对规则语义和实际作答范围，见 [设计评审](design-review.md)。样式版本、实际字体与设计来源留在制作资料。

当日节日、节气通常归日期组，避免与玩法线索混淆。赛博1.2支持把holiday／solar_term模块移至日期旁且仅绘制一次；其余六个editorial预设尚未统一这一信息路由，选用时核对需求，不能直接宣称已经满足。星期和2–5字纯汉字题型名可用逐字正向竖排，保持语义文字、逐字边界与读序记录；时间、标点及长正文不机械竖排。PDF验收按实际坐标重组竖排星期，不能靠隐藏横排文字过检。两行短寄语若末行仅二三字，应优先在句号、分号或其他合适语义点平衡换行；不删改引文，字级调整仍须满足受众可读性与已锁定要求。

内部题号和“当前页／总页数”默认不印，答案通过日期对应；制作资料继续保存全局ID和页面映射。页脚未指定时留空，指定时只绘制用户配置的文字主题或已提供logo，并按实际尺寸计入安全区，检查与下方信息的边界。总标题、信息块标题、提示、编号及页脚各自独立配置，不能把用户标题写死在多个绘图位置，修改合同见 [runtime.md](runtime.md#页面显示配置)。

## 规则出现频率

先按 [答案与玩法交付](answer-and-rules.md) 决定载体与位置，再决定出现频率。“首次玩之前另印一页”是首题之前的独立规则页，不等同于下面的first_occurrence页内规则。插入规则页后重算双面正反面与答案定位。

| 使用方式 | 策略 | 页面处理 |
| --- | --- | --- |
| 整本日历、桌面连续使用 | reference（推荐） | guide.pdf集中印完整规则，日常页默认仅题型名和棋盘 |
| 新手逐步接触不同题型 | first_occurrence | 相同玩法首次在棋盘下印完整简则，后续不重复全文 |
| 单张分发、可独立使用的撕页 | every_puzzle | 每张在棋盘下印完整简则，不再重复提示 |
| 用户已熟悉玩法 | none | 省略玩法文字，必要线索和图例保留 |

当前renderer规则提示默认关闭。用户开启 `show_rule_hint` 时采用直接可理解的句子，必要时分行；避免把三个规则压成“行列去重 · 黑格不共边 · 白格连通”这类术语串。完整简则与提示不在同页重复，也不能把提示当作完整玩法。不要为了每天不同强行改写规则。已知规则逐条件核对后才精简；当前标准独数可以31字涵盖行列去重、黑格不共边、白格连通三项条件。原版完整规则保存在guide.pdf和源记录。未知变体保留全文，不机械设所有谜题相同的字数上限。完整短则下置并预留题页／答案相同的棋盘范围；答案页省略全文但不放大或移动棋盘。参考指南可有多页，连续排版，规则不因分页截断。

- 内容安全区先扣打印机禁区及装订孔／胶口。基线工具无装订时四周12mm；顶部装订可从20mm顶部禁区起测。禁区取更严格值，不机械重复叠加。
- 普通规则正文11pt、题面数字12pt、辅助9pt为起点；大字正文14pt、数字16pt起。每套建议2–3家主要编辑字体，按大日期、年月星期、寄语署名固定分工；月份变体分别存字体和实际样页检查。原源题板保留其原字体与线索几何；派生题面可按风格换字面与外观，另核线索坐标和值、拓扑及有效书写面积，额外家数如实记录，题面数字优先清楚可辨；实际检查全部中文、数字、标点及题目符号字形、嵌入和实物打印效果。
- 常规方格可从7mm起测，需候选数的数独从9mm、大字从10mm、迷宫净通道从4mm起测；按受众、笔具与实际用途核对。异形格量有效书写范围，画线题量落笔通道，不把边长或中心格距当作通用可写尺度。数织含上方／左侧真实线索的完整包围盒，不能只量格盘。
- 普通题线可从细线0.5pt、常规格线0.6pt、主分区1.2pt起测；现有扩展题板线宽归一化仍按成品至少0.5pt处理。装饰刻纹不套用题线下限，关键区别须在目标尺寸下清楚，不靠颜色独占；深色或反白设计另查落笔与打印表现。
- 拥挤先调整装饰和模块关系。未锁定的字号、格距可在实际可读可写的范围内调整并重新核验；仍不适配则筛选规格或报告冲突。不删线索、偷改纸幅或拆页，也不突破用户锁定的字级与题盘尺寸。DOCX和PDF分别检查。

## 可记录的检查

机器检查：真实PDF的MediaBox／页数、字体嵌入、缺字、文本与图形安全边界、内部题位ID、日期答案映射、日期与月格行数、线宽与格距。按appearance核对玩家页该显示和该隐藏的文本；内部题号默认隐藏时通过制作映射校验，不要求PDF中出现技术ID。文本提取不能证明没有重叠。

视觉检查：所有页渲染成缩略图扫查；各模板、每种题型、首次指引、最多线索、六行月份、首尾／跨月／答案页放大检查。记录page_number、检查范围、发现和修复后版本。未做记录则 `visual_qa=pending`，不能自动改成passed。

实物试印：100%／实际大小打印calibration.pdf，量100mm尺，检查细线、字体、铅笔书写、背面方向及孔位。用户实测记录包括设备、纸张、日期和结果；未收到则pending。普通PDF不是专业印前证明。

## 交付状态

`content_verified` 为内容检查；`pdf_structure_verified` 为机器PDF检查；`visual_qa` 为实际渲染检查；`sample_approved` 为用户认可；`physical_print_test` 为实物试印；`human_difficulty_calibrated` 为目标用户试玩。`digital_ready` 需当前scope的内容、计划、结构与视觉全部通过，证据注册合同见 [workflow.md](workflow.md)。保留原始检查报告，release新增最终报告；不要覆盖哈希或手改原manifest伪造通过。实物与用户认可不自动成为数字交付阻塞；合法pending可标明trial交付。

机器工具输出的manifest不能自证用户看过、实物印过或喜欢该设计。风格选择在批量制作前完成，与最终成品验收分开；样稿可先交供选择，已确认的方案不重复审批。给用户展示真实样页和准确状态才进入相应阶段。

配色概念PNG不提供毫米页幅、精确字形／格线或字体嵌入证据。正式彩色PDF须从冻结题目数据重新排入；满版底色同时说明打印机可能保留白边、实际出血与内容安全区。细小反白字、纹样与深色阻挡格逐页看，作答区保持可落笔。
