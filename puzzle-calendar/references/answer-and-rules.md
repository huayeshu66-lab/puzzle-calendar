# 答案与玩法交付

答案安排和玩法安排分别选择，可以组合；同一题型的规则还要区分载体、位置与重复频率。用户指定的其他方案同样保留，先判断可用性，不让预设限制设计。用户未选时按使用情境推荐，不默认启用全部选项。

## 答案方案

| 方案 | 使用与排版 |
| --- | --- |
| 随机放在其他题页背面 | 适合纯纸质双面打印。题页写“答案见1月18日背面”等真实定位；背面标明所解题目的日期，避免拿背面所属日期误认答案 |
| 页面答案二维码（可选） | 普通扫码打开答案查看与下载页，或按用户选择直达原图；文字答案可直接编码；离线图形答案需配套查看器。联网图形方案可用 [Cloudflare Pages](qr-cloudflare.md) |
| 月末／周末集中答案页 | 按日期编排，题页给出所属答案区；便于纯纸查找，避免紧邻本题展示 |
| 独立答案册／答案页组 | 日期索引，题本与答案可分别打印；多人使用时也可由主持人保管 |
| 折叠／遮挡答案区 | 用户愿意折叠或另加遮挡时可选；预留实际折线、遮挡与裁切范围，不能把印出的答案称为自动隐藏 |
| 用户自定义 | 记录放置位置、查找方式、显示内容和打印要求；可与上述方案组合 |

随机背面先确定所有题目、规则插页与装订顺序，再建立完整一对一映射：每题有且仅有一个目标答案，目标不在本题背面；随机种子与映射保存，换风格不能重新随机。避免本题答案直接出现在可见对页。纸张背面所属日期、答案对应日期、PDF页码和实体纸张正反面分别记录，不混用。按真实映射生成题页提示，不让用户自行找规律。

撕页后会丢弃或带走时，核对答案所在纸张仍可取得；选定范围首尾、跨月与最后一题也必须有答案。最终交付按实际单双面顺序组成打印文件，标清翻转方向、装订边和空白背面；先核实际正反面配对，再试印。纸张透印与误露答案在样张中检查。

## 可选二维码

用户选择二维码后再准备托管。普通扫码看图时，推荐直接显示完整答案图的查看页，提供原图和下载入口；也可按已选方式直达原图。使用当前用户自己的托管资源，具体成功流程与全年容量规划见 [Cloudflare 答案托管](qr-cloudflare.md)。纸质答案方案仍独立可用，不能因为已有托管流程而默认启用二维码。

答案图从冻结解导出，保留日期、题型、正确解答符号及必要图例。用户不熟悉玩法时提供已选载体中的规则说明，不靠增加解答数量标题替代规则。测试网址、账户、某一道题的符号和文案不作为其他任务的默认值。

文字答案可以直接编码完整可读内容；普通扫码显示图形答案使用可达链接，离线图形则需用户接受配套查看器。仅解码出文字或图片字节不等于手机能显示答案图。

二维码融入既有日期、题型或页脚结构，保留作答面积。可用中性灰、低饱和蓝绿等深色实色模块，保持对比、完整定位图形和净空；尺寸由真实链接与打印扫码结果确定，不固化某次样稿的尺寸或配色。

分别记录最终PDF解码、在线访问及图像内容、目标手机扫码、图片保存和实物试印。目标网络无法访问时先修复可达性，不将该地址用于正式印刷；未测项保持未测。扫码成功不自动证明下载保存或所有日期的答案对应正确。

## 玩法方案

| 方案 | 使用与排版 |
| --- | --- |
| 独立玩法册 | 各题型完整规则、必要图例与小例题集中编排，日页用题型名定位；可长期放在桌旁查阅 |
| 首次玩之前另印规则页 | 每种玩法或实质规则变体的第一题之前放独立页；在实际翻阅顺序中先读规则，再看到题目；后续不重复全文 |
| 可拆玩法卡／折页速查表 | 常用规则集中，适合打孔装订或随手查阅；注明对应题型，完整条件不能因卡片小而删去 |
| 首次题页内规则 | 完整简则与题盘同页，后续不重复；与前置独立页是不同安排 |
| 每题页内规则 | 单张分发、随意翻阅或独立撕页时可选；给足条件，避免读者必须保留已经丢弃的前页 |
| 不重复玩法文字 | 用户熟悉且明确选择时可用；必要线索、题目条件和图例仍保留 |
| 用户自定义 | 按指定载体、位置和频率安排；例如独立册子配可拆速查卡，不强制只选一种 |

先说明目标如何玩，再给必要例子；不在每天重复长说明，不把看不懂的术语串当简则。前置规则页内的小例题要与正式题目分开，不能泄露正式题答案。玩法材料是否齐备，应结合本次实际交付范围与用户已有材料判断，不能因为全年更早出现过就在独立一月交付中省掉必要玩法。基线`first_occurrence`的题位身份仍以完整正式计划为准，不在每月重置；独立发放后续月份且读者没有前册时，附本月所需规则册或实现首玩前插页。不要通过伪造首次题位来补材料，也不要把独立插页说成现有页内规则功能。

## 记录、验收与现有能力

沿用job的output.answers记录答案模式，instructions记录当前接口可表达的规则策略。更细的答案映射、二维码文本、玩法插页计划和自定义安排，作为已注册的design制作资料保存并由brief引用；同一实际值只保留一个来源。不向现有CLI塞入不存在的参数，也不把前置独立页记作已实现的first_occurrence。

当前基线自动生成独立答案PDF；reference生成独立guide.pdf，first_occurrence与every_puzzle为页内规则。联网图形二维码已有可复用的 Cloudflare 静态托管流程，仍需为当前任务导出、发布、核对并排入PDF，尚非基线CLI的一键功能。随机背面、集中插页、可拆卡和折叠方案需本次实现及验证。prepare对非separate答案和双面有能力提示，应保留；现有release只会按题本／独立答案／私有资料分包，不能自动证明混合正反面或二维码成品通过。

实际制作时核对：冻结题目与答案内容不变；每题答案和定位完整对应；二维码实际呈现符合所选图形／文字及联网／离线方式；首次规则在正确阅读位置；全部插页之后的正反面、方向、日期与装订仍一致。题本中用户指定的答案区和二维码是有意交付，不按泄露误报；未指定的元数据、附件、隐藏层仍不得额外夹带答案。
