# 极繁设计：从主题关系到真实样页

适用于极繁、丰富插画、复杂纹样及陌生主题。目标是丰富而有秩序，同时保留日期与谜题的使用价值。本文件是设计工作方法，不是自动排版预设，也不能保证任意主题一次生成就好看。

## 分开决定六件事

主题讲什么，视觉语言怎样表达，繁简决定细节如何组织，配色决定色彩角色，题型决定玩法结构，模块决定页面需要承载什么。分别沿用用户已选项；“彩色”不等于极繁，“东方”不等于莲花，“装饰艺术”不等于金色太阳。

日期与谜题是核心，其他模块按当前任务选配。视觉留白、装订净空和随手记不是同一用途。选了随手记就留真实连续可写范围；未选时不用为了填版加一个备注框。

## 先判断主题与玩法的关系

| 当前约束 | 下一步设计判断 |
| --- | --- |
| 主题已定，题型未定 | 将主题拆成物体、连接、区域、方向、数量或对称关系，比较少量候选题型；选语义和结构均自然、且可生成验解的方案 |
| 题型或样题已冻结 | 保留题面、答案与规则，选择能适应现有结构的主题表达；不能为适应插画重新出题 |
| 主题与题型都已指定 | 在两者之间找真实相容关系；结构有冲突时改表达方式，无法解决的具体冲突再请用户取舍 |
| 用户只说要极繁 | 依据用途推荐有实质差异的设计方向；主题由当前用户选择或授权推荐，不回落为永久固定菜单 |

例如海水与太阳：若题型未定，海岛对应桥梁节点、海面对应待画桥的通道，通常比“太阳圆，所以放圆形迷宫”更有联系。保留桥梁所需的横竖对齐和可见邻接关系；岛屿外形、海纹和太阳可设计，但题页不得预画桥线、让波纹像桥线，或用装饰遮住可连接节点。太阳可与日期构成呼应，无须强行变成谜题的一部分。

这不是“海洋只能配桥梁”。若用户已定圆形迷宫，可用航路、海流与海岸的语言表达真实通道和墙线，保留入口、出口及唯一通路；不能借换主题改变地图。只有需要换实际结构且用户接受时，才另行生成并重新验解。

陌生题材也按关系判断：钟表工坊可从齿轮的重复几何或刻度组织出发；星际港口可从站点与连接出发；音乐可从节奏和重复单元出发。先明确这种联系是构图比喻还是玩法映射，再核实对应题型，不能因名字相像就宣称已内置新变体。

## 出图前简报

在 `brief.rationale`、`brief.regions` 或任务引用的设计附件中给出下列具体结论，不要求用户填写术语，也不新增未经实现的 CLI 字段。已有明确方案直接沿用，不另设重复审批。

| 简报内容 | 必须说明的设计结果 |
| --- | --- |
| 主题与题型 | 为什么适合；哪些形状对应真实玩法，哪些仅为装饰；题目是否冻结 |
| 整体构图 | 主要视觉落在哪里；日期、题盘与可选内容如何对齐、围合、穿插或平衡；不用“精美高级”代替结构 |
| 复杂感的来源 | 大形建立秩序，中层母题形成节奏，细节丰富局部；明确细节集中区与安静区，不全页同密度 |
| 色彩与字体 | 底色、主色、辅助色、强调色各自承担什么；大日期、日期辅助信息和正文的字形角色如何配合图形；按打印条件设计 |
| 使用空间 | 实际题盘、线索、笔画通路与已选书写模块的范围；装订和裁切条件；装饰不得吃掉这些用途 |
| 素材与验证 | 哪些由结构数据精确排版，哪些由原创插画／纹样完成；需要观察的整页、近景和打印尺度问题 |

先用真实题板和文字估算构图，再做素材。需要丰富边饰时，先决定它怎样承接题盘与日期；需要主体插画时，先让主体结构组织画面。不先生成一幅“中间留个圆”的通用背景，再把任意题盘塞进去。

## 从参考提炼方法，不固化题材

以下四种是已找回参考图中的视觉语言示例，不是极繁的全部选项，也不等于每一款都达到当前用户要求的复杂度。

| 参考语言 | 可迁移的组织方法 | 换题材时可怎样用 |
| --- | --- | --- |
| 植物雕版 | 主体大小有层次，枝脉引导视线，排线随体积变化，细节围绕主形生长 | 可发展为矿物、羽翼或科学器物的雕版语汇；不必每页开花，也不把装饰当科学资料 |
| 复古印刷 | 有力的大色面与留白、海报式字级、刻印线条、少量油墨色形成主次 | 可表现城市、旅行、工业或节庆；不固定为海浪、太阳、山峰 |
| 装饰艺术 | 几何轴线、拱形与阶梯节奏、重复单元、细线与大色面互相平衡 | 可表现未来建筑、天文仪器或剧院；协调边框本身可成立，不要求每题具象化 |
| 纸艺拼贴 | 材料与图形的叠压、大小纹样对比、切边与块面组织不同信息 | 可表现音乐、太空、食物或个人记忆；避免把无关碎片平均撒满四角 |

字体、颜色和纹样随当前主题共同设计。控制主要字体家族并固定角色；复杂感不靠字体不断换。比较两种风格时让构图、线条和材料逻辑产生可辨差异；只换色是配色比较。

用户提供旧图时，将参考保存在当前项目可续用的资产目录，记录来源、喜欢的具体部分和认可范围。缓存路径或模糊风格名不足以长期复用；参考获认可不等于新的真实样页已获认可。引用外部素材另核许可，不照搬品牌作品。

## 制作与评审顺序

1. 用公开题面结构、真实日期和已选模块搭建尺寸正确的构图草案。风格比较保持同日、同题、同信息；如在比较题型选型，明确区分，不能冒称纯风格对比。
2. 按构图制作插画、局部资产或连续纹样。可使用生成工具完成高质量图形，文字、日期、线索、通路及答案仍从核实数据精确排入；不把模型画出的近似格盘当可解题目。
3. 让题面字体、节点、线重和填充回应页面语言，并逐项核对规则语义。使用精美边框可以成立，但框、题盘和日期要共享构图逻辑；题盘成为主题物是可选方法，不是唯一合格路线。
4. 渲染真实目标尺寸。先看缩略图的主次和整体色块，再看实际 A5 等成品尺寸的阅读、落笔和细节质量；完整页与题盘近景都留存。
5. 对照下面问题写观察和修正，再提交样页。美感、繁简程度、玩法正确性、PDF检查与用户选定分别记录；排版检查通过不能代替审美认可。

| 评审问题 | 不成立时优先修改 |
| --- | --- |
| 第一眼能找到日期和题盘，年月日星期是否成组清楚？ | 主视觉比例、字级、对齐与色块，不先添加细节 |
| 主题与题型的关系能具体解释，装饰会不会被误读为线索或答案？仅作页面构图比喻、玩法不承担主题语义也可成立 | 主题映射、符号区别、邻接可见性和题面保护区，不强凑拟物 |
| 丰富度是否有大中小层级，局部密度是否有节奏？ | 主形与次级母题的关系，不把每个空处都填纹样 |
| 图形、字体、颜色和材质是否像同一套设计？ | 收敛不相容的表达，重新分配颜色和字体角色 |
| 实际大小能否读、写、扫码（若已选），装订后是否仍完整？ | 可用尺寸、对比和内容关系；不能只看放大屏幕效果 |
| 复杂度与当前用户的要求相符吗？ | 单独调整密度和层次；“好看”不自动代表“极繁达标” |

用户说“丑”或“不是我要的极繁”时，先从已给反馈定位构图、主题联系、图形质量、色彩或密度的具体问题，再改相应层面。不要只增加纹样、换一个背景或沿用上一位用户的题材。无法从现有反馈判断时，用少量有针对性的比较帮助选择，不要求用户替设计者解决所有细节。

若整批候选都被否定，转入 [全部候选都不满意时](intake.md#全部候选都不满意时)：可放下具象主题，从图形、材料与构图关系探索；保留已认可的局部，不只扩大主题列表。
